# Iris Dataset — Exploratory Data Analysis 🌸

## 📌 Project Overview

This project explores the Iris dataset using Python to understand the differences between three Iris flower species through data analysis and visualization.

## 🎯 Objectives

* Explore the dataset and its features.
* Check for missing values.
* Generate descriptive statistics.
* Compare flower species using visualizations.
* Identify patterns between petal measurements.

## 🛠️ Tools & Libraries

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab / Jupyter Notebook

## 📊 Analysis

The notebook includes:

* Dataset overview and summary statistics
* Species distribution
* Petal length comparison
* Relationship between petal length and petal width

## 📁 Project Structure

* `iris-data-analysis.ipynb` — Data analysis notebook
* `README.md` — Project documentation

## ▶️ How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Install the required libraries if they are not already installed.
3. Run the notebook cells in order.
